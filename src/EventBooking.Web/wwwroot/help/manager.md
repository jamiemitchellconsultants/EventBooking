# Manager guide

Managers speak for one appointment type. They propose events, accept or decline what others propose, and set how many attendees each event can take.

## Negotiation

Negotiation is where events are agreed. Anyone scoped to manage an appointment type can propose an event: pick a location, a date and start time, a duration, and the headcount each attending type may bring. The proposal then waits for every listed type to accept it.

Accepting records your headcount against the proposal. Once all types have accepted, the event is confirmed and invitations can offer it. Withdrawing an acceptance or the whole proposal is possible while the event is still open; confirmed events are cancelled from event operations instead.

## Capacity

Capacity is agreed per appointment type on each event. The headcount you accept is the number of places your type may fill. Remaining capacity falls as attendees book and rises again when bookings are cancelled. Adjusting capacity after confirmation is allowed but can never drop below the places already booked.

## Appointment workspace

The appointment workspace is the day-of-event view shared with appointment staff: the roster of booked attendees, who has checked in, and each appointment's outcome. Managers use it to follow the event they agreed, and to correct an outcome recorded in error.

## Audit search

Audit search answers what changed, who changed it and when. Filter by date range, actor, action or entity, then page through the results. Timestamps are shown in UTC so entries from every location compare directly.
